# checkpoint / dataset：验收清单

## G0 能跑

- [ ] 真实运行跑通前向、反向、optimizer.step 与一次 checkpoint 写入
- [ ] checkpoint 实现名与版本已记录
- [ ] dataset 布局与真实训练一致（文件切分与格式未改）
- [ ] 运行配置已记录：模型 commit、框架版本、依赖 lock、拓扑、存储挂载

## G1 旁路可跑

- [ ] meta device 构建的模型能跑完与 G0 相同的流程
- [ ] `param.grad` 存在且逻辑尺寸与真实一致
- [ ] `state_dict()` 的键结构与真实运行核对一致
- [ ] 保真边界表已填写，存储路径均不为 `L0`
- [ ] 异步 checkpoint 的时序折算规则已写明

## G2 小规模对齐

- [ ] 真实与旁路各跑一次，观测配置相同
- [ ] 应用层与系统层总字节数偏差 ≤ 1%，或偏差已解释
- [ ] 观测开销单独测量，关键指标变化 ≤ 3%
- [ ] 全部分项在容差内，或偏差已归因并经评审
- [ ] 对齐报告已上传并回链

## G3 逐级 scaling

- [ ] S0 → S1 → S2 → S3 → S4 → S5 逐级执行，未跳级
- [ ] 每级都有完整度量，不只测带宽
- [ ] 每条不变量的相邻级偏差在容差内
- [ ] 元数据操作数与数据字节数分开报告
- [ ] 聚合带宽的饱和拐点已标出
- [ ] 异步写入的时序折算已应用
- [ ] 尾延迟（P99/P999）已按节点拆分排查

## G4 结论登记

- [ ] `latest_run` 已由评估服务写入，回链三要素齐全
- [ ] 覆盖度矩阵已更新
- [ ] 未解决的偏差已登记进 `playbook/pitfalls.md`
- [ ] checkpoint 实现、框架版本与服务版本均可查
