# kvcache：验收清单

## G0 能跑

- [ ] 真实推理跑通，记录请求数、输入输出长度分布
- [ ] 每 token KV 写入字节的计算值已算出
- [ ] 框架版本、模型 commit、缓存配置、负载配置均已记录

## G1 旁路可跑

- [ ] meta device 构建的模型能跑完相同负载
- [ ] 占位 attention 真的按块表与偏移访问了 KV
- [ ] 采样与停止条件保留，输出长度分布与真实一致
- [ ] 保真边界表已填写，KV 读写路径不为 `L0`
- [ ] 框架适配层通过最小用例，失败时显式报错

## G2 小规模对齐

- [ ] prefill 与 decode 分别判定
- [ ] 每 token KV 写入字节的相对误差 ≤ 1%
- [ ] 前缀命中率两侧一致
- [ ] 读放大倍数在容差内
- [ ] 观测开销单独测量，关键指标变化 ≤ 3%
- [ ] 对齐报告已上传并回链

## G3 逐级 scaling

- [ ] 换模型：每个注意力变体 ≥ 5 个模型通过
- [ ] 换框架：vllm / sglang / deepinfer 全部通过
- [ ] 放大参数规模：每 token KV 字节保持
- [ ] 放大集群规模至十万卡：跨节点流量、对端分布、尾延迟均已采集
- [ ] 传输与存储的时间重叠关系已记录
- [ ] 驱逐路径已确认被触发（显存配额不足时）

## G4 结论登记

- [ ] `latest_run` 已由评估服务写入，回链三要素齐全
- [ ] 适配矩阵已更新
- [ ] 单机无法复现的时序结论已明确标注不可用
- [ ] 未解决的偏差已登记进 `playbook/pitfalls.md`
- [ ] 三个框架的版本、适配层版本与服务版本均可查
