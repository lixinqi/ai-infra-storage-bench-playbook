# 本配方专属校验

放只对这个评估集成立的校验，例如：

- 分片键结构核对：`state_dict()` 的键与真实运行一致。
- 每 token KV 写入字节核对：与模型配置算出的值比对。
- 前缀命中率核对：与负载配置的理论命中率比对。

通用校验放在仓库根的 `checks/`，不要在这里重复实现。

每个脚本的约定：

- 入参：`--run-dir <path>`，目录内含 `metrics.json` 与 `manifest.json`。
- 退出码：0 通过，1 不通过，2 缺依赖或输入缺失。
- 输出：一行 JSON 到标准输出，字段 `{"check": "<name>", "status": "pass|fail|skip", "detail": "..."}`。
