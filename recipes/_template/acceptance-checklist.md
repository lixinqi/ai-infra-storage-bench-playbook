# 验收清单模板

每道门都要勾。未勾选的门不允许进入下一道门。勾选时附上回链或证据位置。

## G0 能跑

- [ ] 不旁路的状态下，目标代码能跑完一次前向或一次预填充
- [ ] 运行配置已记录（模型 commit、框架版本、依赖 lock、拓扑）
- [ ] 最小可运行配置已写成文件，能重复执行

## G1 旁路可跑

- [ ] 旁路实现后能跑完与 G0 相同的流程
- [ ] `recipe.yaml` 的 `fidelity_boundary` 已逐行填写，无空字段
- [ ] 存储与传输路径的 `fidelity` 均不为 `L0`
- [ ] `known_bias` 已写明偏差方向

## G2 小规模对齐

- [ ] 真实运行与旁路运行各完成一次，观测配置相同
- [ ] 应用层与系统层总字节数偏差 ≤ 1%，或偏差已解释
- [ ] 观测开销单独测量，关键指标变化 ≤ 3%
- [ ] 全部对齐分项在容差内，或偏差已归因并经评审
- [ ] 对齐报告已上传并回链

## G3 逐级 scaling

- [ ] 每一级都有完整度量，不是只测带宽
- [ ] 每条不变量的相邻级偏差在容差内
- [ ] 无不变量单调恶化
- [ ] 非线性来源已排查，偏差归因已写
- [ ] 下一级预测值与预测依据已写

## G4 结论登记

- [ ] `latest_run` 已由评估服务写入，回链三要素齐全
- [ ] 覆盖度矩阵已更新
- [ ] 未解决的偏差已登记进 `playbook/pitfalls.md`
- [ ] 配方版本、指标版本、服务版本一致且可查
