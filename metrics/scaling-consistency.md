# Scaling 一致性

版本 1.0.0。

## 定义

从较小规模外推到较大规模时，声明的 scaling 不变量保持在容差内的程度。用于判定外推依据是否成立，是阶段门 G3 的门槛。

## 口径

对每条不变量，计算相邻规模档位之间的偏差：

```text
偏差(i) = |值(Si) - 值(Si-1)| / 值(Si-1)
```

特殊情况：

- 值本身是分布时，用分布距离（与 IO pattern 对齐度相同的分桶方式）。
- 值接近 0 时改用绝对差，阈值单独声明。
- 不小于三级时，同时报告最大相邻偏差与首末级总偏差。

判定看三件事：

1. 每条不变量的相邻级偏差在它自己的容差内。
2. 首末级偏差在 `first_last` 内。
3. 偏差随规模的变化没有单调漂移。每一级都朝同一方向漂移时，即使每级都在容差内，也说明不变量选错了。

## 阈值

默认值写在配方的 `metrics.yaml`：

```yaml
tolerance:
  per_level: "10%"
  first_last: "15%"
```

某条不变量需要更宽或更紧，在输入文件里给它单独写 `tolerance`；不写就用 `per_level`。两边都没有时报错，不给默认值。

## 采集

输入是每一级运行的度量值：

```json
{
  "levels": ["S0", "S1", "S2"],
  "invariants": {
    "per_parameter_bytes": {"values": [16.0, 16.2, 15.9]},
    "write_concurrency_p50": {"values": [4, 4.5, 4.2], "tolerance": 0.3}
  }
}
```

`levels` 的取值必须匹配 `^S[0-9]+$`。与配方 `scaling_plan.levels` 的一致性由评审检查：脚本只知道输入里有几级，不知道配方应该有几级。计算脚本：`checks/check_scaling_consistency.py`。

## 判定

| 情况 | 结论 |
|---|---|
| 全部不变量在全部级别容差内，无单调漂移 | 一致，允许外推 |
| 有不变量超出容差，偏差有归因且不影响目标结论 | 有条件一致，需评审 |
| 有不变量超出容差，归因不明 | 不一致，停止外推 |
| 有不变量在容差内但单调漂移 | 不变量选错，停止外推 |
| 任一级缺数据、阈值缺失 | 不可比，补齐后再算 |

## 已知限制

- 一致性成立只说明"外推的形式依据成立"，不说明外推后的绝对数值一定准。
- 不变量选得少时容易通过，但外推可信度低；指标本身不能防止选错不变量。
- 只沿一个维度放大时结论清晰，多维度同时放大时必须分别计算，不能合并成一个数。
