# 决策记录（ADR）

记录会长期影响评估口径的取舍。日常改动不写在这里。

## 什么时候写

- 选了某种旁路手段，排除了另一种。
- 定义了新的 scaling 不变量，或放弃某个不变量。
- 评估集版本与评估服务版本如何绑定。
- 任何会让历史结论不可比的改动。

## 命名

`NNNN-短描述.md`，四位编号递增，描述用小写连字符英文。编号不复用。

## 结构

```text
# NNNN 标题

## 状态
提议 / 采纳 / 废弃，以及日期

## 背景
为什么现在要做这个决定，约束是什么

## 候选
列出被考虑过的选项，每个一行，写清代价

## 决定
选了哪个，为什么

## 后果
这个决定带来什么，包括需要接受的不便

## 相关
指向受影响的文档与配方
```
